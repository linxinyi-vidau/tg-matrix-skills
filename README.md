# TG Matrix Skills

Hermes / Vidau Skill package for TG Matrix Telegram lead generation.

## Install

Use this Skill index URL in Hermes / Vidau:

```text
https://linxinyi-vidau.github.io/tg-matrix-skills/.well-known/skills/index.json
```

## Runtime Tooling

This Skill teaches the agent how to use TG Matrix. The actual tools are provided by the TG Matrix MCP server:

```text
https://tg-matrix-agent.vidau.info/mcp
```

Users do not need to provide Telegram `api_id` or `api_hash`; those are configured on the TG Matrix server.
